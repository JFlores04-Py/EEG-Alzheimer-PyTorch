# 🧠 EEG Alzheimer's Classification with PyTorch

**Goal:** Classify Alzheimer's Disease vs Healthy controls from EEG signals.

## Results
- **Test Accuracy:** 90.0%
- **Model:** 3-layer Fully Connected Neural Network
- **Features:** PSD from 5 frequency bands across 19 EEG channels

## Key Skills
- PyTorch binary classification
- Early stopping & dropout regularization
- Baseline comparison (Logistic Regression)

📓 **Notebook:** `EEG_Alzheimer_PyTorch.ipynb`
